# Validation plan

ZedThema should be evaluated as a research instrument, not only as software.

## Phase 1: transcription validation

Use researcher-verified transcripts for a sample of interviews. Compare the model transcript with the reference transcript and report word-level and meaning-relevant errors.

For Zambian-language work, report results separately by language.

## Phase 2: coding validation

Create a gold-standard coding set with at least two trained human researchers. Compare:

1. manual coding;
2. one AI model;
3. a second AI model;
4. AI plus human review.

Do not use agreement alone as proof of validity. Review disagreements and unsupported quotations.

## Phase 3: efficiency

Measure:

- minutes per transcript;
- researcher review time;
- number of suggestions reviewed;
- number of edits;
- number of rejected suggestions.

## Phase 4: multilingual robustness

Repeat the evaluation across languages and document where transcription errors change coding decisions.

## Phase 5: reproducibility

Run the same source and codebook twice and compare outputs. Record model name, model version, prompt version and analysis settings.
